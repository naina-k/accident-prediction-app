# 🚦 Accident Prediction System

## 📌 Project Overview
This project is an AI-based Accident Prediction System developed using Machine Learning. It analyzes various traffic and environmental factors such as speed, weather, visibility, and time to predict the severity of road accidents.

The system is designed with an interactive dashboard that helps users understand accident patterns and make predictions in real time.

---

## 🎯 Aim
To develop a machine learning-based system that predicts accident severity and helps in improving road safety.

---

## 🎯 Objectives
- To analyze accident-related data
- To train a machine learning model for prediction
- To visualize accident trends using graphs
- To build an interactive user interface
- To provide real-time prediction based on user input

---

## 🛠️ Technologies Used
- Python
- Machine Learning (Random Forest)
- Streamlit (for UI)
- Pandas & NumPy
- Matplotlib

---

## 📊 Dataset
The dataset contains accident-related features such as:
- Speed
- Weather conditions
- Visibility
- Wind speed
- Time (hour)
- Accident severity

---

## 🤖 Model Information
- Algorithm Used: Random Forest Classifier
- Training Accuracy: 100% (on small dataset)
- Evaluation Method: Confusion Matrix

---

## 📈 Features
- 📊 Data visualization dashboard
- 📉 Confusion matrix display
- 📈 Accident severity analysis graph
- 🔮 Real-time prediction system
- 🖥️ User-friendly interface
